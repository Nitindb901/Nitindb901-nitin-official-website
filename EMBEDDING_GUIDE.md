## 🎯 Embedding Options

### Option 1: Full Page Embed (Recommended)
Use this to embed the complete dashboard as an iframe:

```html
<!-- Dashboard Embed - Full Width -->
<div style="width: 100%; margin: 20px 0;">
  <h2 style="text-align: center; margin-bottom: 20px;">
    📊 Interactive Business Intelligence Dashboard
  </h2>
  <iframe 
    src="dashboard_interactive.html" 
    width="100%" 
    height="900px" 
    style="border: 2px solid #2b3b56; border-radius: 12px; background: #000;"
    title="Interactive BI Dashboard">
  </iframe>
</div>
```

### Option 2: Responsive Embed
Use this for a responsive iframe that maintains aspect ratio:

```html
<!-- Responsive Dashboard Embed -->
<div style="position: relative; width: 100%; padding-bottom: 75%; overflow: hidden; margin: 20px 0;">
  <iframe 
    src="dashboard_interactive.html" 
    style="position: absolute; top: 0; left: 0; width: 100%; height: 100%; border: 2px solid #2b3b56; border-radius: 12px;"
    title="Interactive BI Dashboard">
  </iframe>
</div>
```

### Option 3: Insights Page Embed
